# 🎓 Vuzify

**Vuzify** — удобное и быстрое Android-приложение для просмотра расписания занятий в вузах с упором на эстетичный дизайн, плавную производительность (120 FPS) и надежный офлайн-режим.

---

## ✨ Особенности

* 🎨 **Продуманный дизайн:** Нежная пастельная палитра (Soft Lavender), скругленные карточки, цветовые бейджи типов занятий (лабораторные, практики, зачеты, лекции) и четкие плашки аудиторий.
* ⚡ **120 FPS и мгновенная навигация:** Плавный свайп между днями (`HorizontalPager`) с синхронизацией календаря без единого фриза.
* 📶 **Надежный офлайн-режим:** Архитектура *Single Source of Truth* на базе **Room Database**. Расписание мгновенно загружается из локальной базы ($0\text{ мс}$ ожидания), а при отсутствии сети отображается время последнего сохранения.
* 🛡️ **Обход защиты вуза (StormWall):** Фоновый `Headless Session Bridge` для автоматического получения токенов сессии без необходимости ручного ввода капчи в большинстве случаев.
* 🚀 **Прямой JSON API:** Работает с внутренними Bitrix AJAX-эндпоинтами университета для максимальной скорости и точности парсинга.

---

## 🛠️ Стек технологий

* **Язык:** Kotlin 2.1
* **UI:** Jetpack Compose + Material 3
* **База данных:** Room DB (SQLite) + Coroutines Flow
* **Сеть & Сериализация:** Ktor Client + OkHttp Engine + Kotlinx Serialization
* **Сборка:** Gradle Version Catalogs (`libs.versions.toml`)

---

## 🚀 Запуск и сборка

1. Откройте проект в **Android Studio** (`File -> Open -> Vuzify`).
2. Дождитесь автоматической синхронизации Gradle.
3. Подключите Android-устройство по USB (или запустите эмулятор).
4. Нажмите кнопку **Run (Shift + F10)**.
